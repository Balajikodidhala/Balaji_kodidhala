## Featured project

### ☕ Mysuru Coffee Bar

A colorful cafe ordering website with table selection, menu ordering, cart
review, and a counter dashboard for incoming orders.

- Choose from Tables 1 through 8
- Place orders directly from a phone
- Send orders to the counter
- Track orders from `new` to `preparing` to `served`
- Store orders with Supabase and use a local fallback during development
